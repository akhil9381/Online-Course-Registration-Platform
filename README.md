# Online Course Registration Portal

## Project Overview

The Online Course Registration Portal is a responsive web application developed for a training institute. It allows students to explore available courses, register online, learn about the institute, and contact the administration through a user-friendly interface.

The project is built using HTML5, CSS3, Bootstrap 5, and Bootstrap Icons to provide a modern and responsive design.

---

## Features

### Home Page
- Responsive Navigation Bar
- Hero Section with Institute Introduction
- Bootstrap Carousel/Banner
- Featured Courses Section
- Student Testimonials
- Footer with Contact Information and Social Media Links

### Courses Page
- Display of Available Courses
- Bootstrap Card Layout
- Course Duration and Fee Information
- Enroll/View Details Buttons

### Registration Page
- Student Registration Form
- Course Selection Dropdown
- Resume Upload Option
- Terms & Conditions Checkbox
- Registration Success Alert

### About Us Page
- Institute History
- Vision Statement
- Mission Statement
- Faculty Information Using Bootstrap Cards

### Contact Us Page
- Contact Form
- Address and Contact Information
- Google Map Placeholder
- FAQ Section Using Bootstrap Accordion
